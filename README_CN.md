# Hotkey Overlay

Blender 视口按键鼠标悬浮显示插件（v1.12.3）

## 功能
- **黑色简约浮窗 UI（v1.12.1 默认）**：近黑卡片 + Blender 橙键位强调 + 中灰细边框，与 Blender 本体暗色 UI 一致；圆角卡片与最近按键块（自定义 SDF 抗锯齿 shader，编译失败自动回退直角）
- **最近按键块底色独立可调（v1.12.2）**：面板外观区新增"最近按键块底色"色板，与键位文字色分离
- 按键/鼠标操作实时显示在常驻提示卡底部的状态行（类 Screen Keys 效果）：最近 3 个按键大字号、按年龄渐隐
- **常驻快捷键提示卡片**（视口左上角，一直可见）：物体/编辑/姿态/雕刻四模式，每模式 13+ 条高频快捷键
- **提示卡可拖拽移动**：按住卡片任意位置拖动即可；单击标题栏折叠/展开；面板提供 X/Y 数值微调与一键重置位置
- **自定义调色 + 透明度**：卡片背景/标题栏/标题字/键位字/说明字/边框色，以及最近按键文字色、最近按键块底色共 8 项配色自由调整；背景板透明度控制卡片整体，按键块透明度控制最近按键/按住行键块
- **拖动不误触框选**：拖拽/折叠卡片时鼠标事件由插件消费，不再穿透触发 Blender 的框选操作
- **按键历史教学渐隐**：状态行显示最近 3 个按键（最新在左、按年龄渐隐），连按多键时教学演示更清晰
- **按住修饰键常驻显示**：按住 Ctrl/Shift/Alt 时状态行常驻显示，松开即消失（Screencast-Keys 风格）
- **模式跟随**：Tab 切换编辑/姿态/雕刻模式后，提示卡自动切换对应模式的提示文案
- **外观设置自动保存**：调色、透明度、字体、卡片位置、折叠状态修改后自动写入配置（0.8s 防抖），重启/重载工程自动恢复
- 一键从系统快捷键自动生成提示：读取你自定义的键位配置，提示显示你的真实按键；修改快捷键后点按钮刷新即可
- 提示文字完全自定义，支持一键恢复默认文案
- 配置自动保存，支持导入导出 json 备份文件
- 打开 blend 工程后自动启动捕获；卸载插件时完整清理绘制句柄、事件处理器、模态实例，无后台残留

## 兼容版本
- **仅支持 Blender 4.2 ~ 5.x（扩展包形式）**；实测 Blender 5.2.2 LTS（Steam 版）。
- 不再支持 Blender 3.6 ~ 4.1 legacy 附加组件（圆角 SDF shader 依赖 `GPUShaderCreateInfo`，为 4.0+ API；扩展包 manifest 已将 `blender_version_min` 锁为 4.2.0）。

## 安装
1. 下载 `hotkey_overlay_v1.12.3.zip`（zip 内为 `hotkey_overlay/` 目录，含 `hotkey_overlay.py` + `__init__.py` + `blender_manifest.toml`）。
2. 编辑 → 偏好设置 → 扩展 → 安装，选择压缩包并启用。

> 升级旧版本前，请先在扩展面板移除旧版 Hotkey Overlay，避免同名类冲突。

## 使用
1. 在 3D 视图按 N 键打开侧边栏，找到 HotkeyOverlay 面板。
2. 打开或重新加载 blend 工程后，输入捕获会自动启动（左上角出现模式提示框，按键时状态行弹出最近按键块）。
3. 也可以点击面板顶部按钮手动开启/停止输入捕获。
4. 想按自己改过的键位生成提示：下拉选择模式 → 点击【从系统快捷键生成当前模式提示】。
5. 拖动提示卡到喜欢的位置；单击标题栏折叠；在【外观自定义】调整配色，可一键【恢复默认外观】或切换【简约玻璃风】预设；在【卡片位置与折叠】微调 X/Y 或重置。
6. 修改提示文本、调节显示时长，保存配置。

## Blender 5.x 使用注意
- 若首次启动未看到提示卡片，重开一次 3D 视口（或按一次 N 键）触发重绘即可
- 中文输入法可能先拦截字母键（出现候选词框），这是系统输入法行为，并非插件问题；改用英文输入或功能键即可正常捕捉
