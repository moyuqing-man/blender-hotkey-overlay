# Hotkey Overlay
Blender 视口按键鼠标悬浮显示插件

## 功能
- 实时显示键盘按键、鼠标点击与滚轮操作，带淡出动画
- 物体/编辑/姿态/雕刻模式常驻快捷键提示
- 提示文字完全自定义，支持一键恢复默认文案
- 配置自动保存，支持导入导出 json 备份文件
- UI面板提供按钮，可手动开启/停止输入捕获

## 兼容版本
- 旧附加组件包：Blender 3.6 ~ 4.1（直接安装py文件）
- 新版扩展包：Blender 4.2 ~ 5.x（使用extension压缩包）

## 安装
### Blender 3.6‑4.1
1. 下载 `hotkey_overlay_legacy.zip`
2. 编辑 → 偏好设置 → 附加组件 → 安装，选择压缩包并启用。

### Blender 4.2 及以上
1. 下载 `hotkey_overlay_extension.zip`
2. 编辑 → 偏好设置 → 扩展 → 安装，选择压缩包并启用。

## 使用
1. 在3D视图按 N 键打开侧边栏，找到 Hotkey Overlay 面板。
2. 打开或者重新加载blend工程后，输入捕获会自动启动。
3. 可以点击面板顶部按钮手动开启/停止按键捕获。
4. 修改提示文本，调节字体大小、透明度，保存配置。
