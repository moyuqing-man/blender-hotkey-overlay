# Hotkey Overlay

Blender 视口按键鼠标悬浮显示插件（v1.12.1）

## 功能
- **玻璃拟态 UI（v1.12.0）**：卡片/标题栏/键位块全部圆角化，磨砂半透明背景 + 顶部高光 + 三层悬浮投影 + 圆角描边，简约标题栏；面板新增"简约玻璃风"一键预设
- 屏幕中央大卡片显示按键/鼠标操作（类 Screen Keys 效果）：大字号、半透明深色背景、金黄高亮边框、淡入淡出 + 上浮动画
- **常驻快捷键提示卡片**（视口左上角，一直可见）：物体/编辑/姿态/雕刻四模式，每模式 13+ 条高频快捷键
- **提示卡可拖拽移动**：按住卡片任意位置（标题栏或内容区）拖动即可；按住 Ctrl 拖动为 1/4 速度精细微调；面板提供 X/Y 数值微调与一键重置位置
- **单击标题栏折叠/展开**：卡片收起为标题 + 最近按键状态行，再点展开
- **自定义调色 + 卡片透明度**：背景色、标题栏色、标题字、键位字、说明字、边框色六项自由配色；「卡片透明度」滑条控制**整卡**不透明度——卡片主体、标题栏、边框、投影、文字全部生效（实时）
- **拖动不误触框选**：拖拽/折叠卡片时鼠标事件由插件消费，不再穿透触发 Blender 的框选操作
- **按键历史教学渐隐**：状态行显示最近 3 个按键（最新在左、按年龄渐隐），连按多键时教学演示更清晰
- **模式跟随**：Tab 切换编辑/姿态/雕刻模式后，提示卡自动切换对应模式的提示文案
- **外观设置自动保存**：调色、透明度、字体、卡片位置、折叠状态修改后自动写入配置（0.8s 防抖），重启/重载工程自动恢复
- **最近按键即时更新**：捕获到按键后立即刷新状态行（修复旧版按键后状态行不刷新问题）
- 一键从系统快捷键自动生成提示：读取你自定义的键位配置，提示显示你的真实按键；修改快捷键后点按钮刷新即可
- 提示文字完全自定义，支持一键恢复默认文案
- 配置自动保存，支持导入导出 json 备份文件
- UI 面板提供按钮，可手动开启/停止输入捕获；打开 blend 工程后自动启动捕获
- 卸载插件时完整清理绘制句柄、事件处理器、模态实例，无后台残留

## 兼容版本
- 旧附加组件包：Blender 3.6 ~ 4.1（直接安装 py 文件）
- 新版扩展包：Blender 4.2 ~ 5.x（使用 extension 压缩包；自动兼容 5.x 中 keymap 名称变化）

## 安装
### Blender 3.6-4.1
1. 下载 `hotkey_overlay_legacy.zip`（zip 内直接放 `hotkey_overlay.py`）
2. 编辑 → 偏好设置 → 附加组件 → 安装，选择压缩包并启用。

### Blender 4.2 及以上
1. 下载 `hotkey_overlay_v1.9.6.zip`（zip 内为 `hotkey_overlay/` 目录，含 `hotkey_overlay.py` + `__init__.py` + `blender_manifest.toml`）
2. 编辑 → 偏好设置 → 扩展 → 安装，选择压缩包并启用。

> 升级旧版本前，请先在扩展面板移除旧版 Hotkey Overlay，避免同名类冲突。

## 使用
1. 在 3D 视图按 N 键打开侧边栏，找到 HotkeyOverlay 面板。
2. 打开或重新加载 blend 工程后，输入捕获会自动启动（左上角出现模式提示框，按键时屏幕中央弹出大卡片）。
3. 也可以点击面板顶部按钮手动开启/停止输入捕获。
4. 想按自己改过的键位生成提示：下拉选择模式 → 点击【从系统快捷键生成当前模式提示】。
5. 拖动提示卡到喜欢的位置；单击标题栏折叠；在【外观自定义】调整配色、背景板大小（原按键字体大小）、背景板透明度（原按键背景透明度）与卡片透明度，可一键【恢复默认外观】；在【卡片位置与折叠】微调 X/Y 或重置。
6. 修改提示文本、调节显示时长，保存配置。

## Blender 5.2 使用注意
- 若首次启动未看到提示卡片，重开一次 3D 视口（或按一次 N 键）触发重绘即可
- 中文输入法可能先拦截字母键（出现候选词框），这是系统输入法行为，并非插件问题；改用英文输入或功能键即可正常捕捉
