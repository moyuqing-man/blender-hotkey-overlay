# Hotkey Overlay
Real‑time keyboard & mouse overlay add‑on for Blender.
Show pressed keys, mouse clicks and persistent mode hotkey hints inside 3D Viewport.

## Features
‑ Real‑time display for keyboard keys and mouse operations, fade‑out animation.
‑ Persistent hot‑key hints for Object / Edit / Pose / Sculpt mode.
‑ Fully editable hint texts, support reset to default.
‑ Auto‑save configuration, import / export json backup file.
‑ Manual start / stop capture button in UI panel.

## Compatibility
- Legacy add‑on: Blender 3.6 ~ 4.1 (install single `.py` file)
- Extension package: Blender 4.2 ~ 5.x (use zip extension package)

## Installation
### Blender 3.6‑4.1
1. Download `hotkey_overlay_legacy.zip`
2. Edit → Preferences → Add‑ons → Install → select zip and enable.

### Blender 4.2+
1. Download `hotkey_overlay_extension.zip`
2. Edit → Preferences → Extensions → Install → select zip and enable.

## Usage
1. Open 3D View, press `N` key to open side panel, find `Hotkey Overlay`.
2. After opening/reloading blend file, input capture will start automatically.
3. You can manually click button to start / stop input capture.
4. Customize hint text, adjust font size, opacity, save your config.
